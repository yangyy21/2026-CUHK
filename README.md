# CUHK Building Carbon Map

Interactive 3D GIS for planning-level embodied and operational carbon estimates of CUHK buildings.

## Open the map

Open `index.html`, or enable GitHub Pages for this repository.

## Method note

The map presents research estimates rather than audited building carbon accounts. Operational results use EnergyPlus archetype simulations with Hong Kong weather and are not calibrated to CUHK utility meters.
